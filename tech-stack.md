# Tech Stack

## Frontend
- **Framework**: Next.js
- **UI Library**: React
- **Styling**: Tailwind CSS
- **Graph Visualization**: React Flow
- **Package Manager**: pnpm

## Backend
- **Runtime**: Bun
- **Framework**: Next.js (API Routes)
- **API Layer**: tRPC
- **Package Manager**: pnpm

## Database
- **Database**: SQLite
- **ORM**: Drizzle
- **Schema**: JSON columns for flexible properties

## Development Tools
- **Linting & Formatting**: Biome
- **Git Hooks**: Husky
- **Type Safety**: TypeScript (end-to-end with tRPC)

## Data Processing
- **File Handling**: Next.js built-in file handling
- **CSV Processing**: Built-in with Next.js API routes
- **Data Export**: CSV export via API routes
